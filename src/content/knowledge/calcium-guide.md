# 鈣質的功效與日常補充指南

![](/uploads/blog-calcium-guide.jpg)
鈣質不只與骨骼健康有關，也參與肌肉收縮、神經傳導、血液凝固與心臟運作。人體無法自行製造鈣，因此需要每天從飲食中穩定補充。

補鈣的重點不是偶爾吃大量鈣片，而是把乳品、豆製品、連骨小魚及深綠色蔬菜分散安排在每天的飲食中，同時配合維生素 D、運動與良好生活習慣。

## 鈣質是什麼

鈣是人體含量最多的礦物質，絕大部分儲存在骨骼與牙齒中，少部分則存在血液和其他組織。

血液中的鈣濃度必須維持穩定。當飲食中的鈣長期不足時，身體可能從骨骼中調度鈣質，以維持肌肉、神經與心臟等重要功能。這也是為什麼缺鈣初期不一定有明顯感覺，卻可能在多年後影響骨骼健康。

## 鈣質對身體有哪些作用

* **建立並維持骨骼與牙齒**：骨骼會持續進行新陳代謝，舊的骨組織被分解，新的骨組織再形成。兒童及青少年需要鈣來累積骨本，成年人則需要足夠的鈣來減少骨質流失。鈣並不是預防骨質疏鬆的唯一因素，維生素 D、蛋白質、荷重運動、日照、荷爾蒙及生活習慣也會影響骨骼健康。
* **幫助肌肉正常收縮**：從走路、抬手到心臟跳動，都需要鈣離子參與肌肉的收縮與放鬆。鈣質不足或血鈣異常時，可能影響正常的肌肉功能。
* **協助神經傳遞訊息**：神經細胞需要鈣來傳遞訊號，讓大腦能與身體各部位溝通。這項功能與動作控制、感覺反應及其他生理活動都有關。
* **參與血液凝固與荷爾蒙分泌**：鈣也是凝血反應中的重要成分，並參與部分荷爾蒙與酵素的分泌和作用。

## 每天需要多少鈣

依台灣國人膳食營養素參考攝取量，不同年齡每日建議量如下：

| 年齡      | 每日建議鈣攝取量 |
| :------ | :------- |
| 1～3歲    | 500毫克    |
| 4～6歲    | 600毫克    |
| 7～9歲    | 800毫克    |
| 10～12歲  | 1,000毫克  |
| 13～18歲  | 1,200毫克  |
| 19歲以上成人 | 1,000毫克  |

青少年正處於快速累積骨本的階段，因此鈣需求量比一般成年人高。懷孕及哺乳期間不一定需要額外增加鈣量，但仍應達到原年齡層的建議攝取量。

> **上限提醒**：一般成人每日總攝取量不宜長期超過 2,500 毫克。這項上限包括食物、營養強化食品及補充品中的鈣，不代表每天都應吃到上限。

## 哪些人較容易攝取不足

以下族群應特別留意日常鈣攝取：

* 很少喝牛奶或食用乳製品的人
* 乳糖不耐、牛奶過敏或採全素飲食者
* 正在成長的兒童與青少年
* 停經後女性與高齡者
* 長期節食或飲食種類非常單一者
* 很少日曬、缺乏運動或維生素 D 不足者
* 患有腸胃吸收、腎臟、副甲狀腺等相關疾病者

單靠抽血測量血鈣，通常無法直接判斷平日是否吃夠鈣，因為身體會優先維持血鈣穩定。若需要評估骨骼狀況，應由醫療人員綜合飲食、病史與骨密度等資料判斷。

## 日常高鈣食物與含量

天然食物會因品種與製作方式而不同；豆腐、植物奶、穀片等產品差異尤其大，購買時仍應查看營養標示。

| 食物             | 常見食用份量 | 約含鈣量   |
| :------------- | :----- | :----- |
| **低脂鮮奶**       | 240毫升  | 240毫克  |
| **原味低脂優格**     | 約227公克 | 415毫克  |
| **添加鈣豆奶**      | 240毫升  | 約300毫克 |
| **莫札瑞拉起司**     | 約43公克  | 333毫克  |
| **帶骨沙丁魚罐頭**    | 約85公克  | 325毫克  |
| **硫酸鈣製成的傳統豆腐** | 約半杯    | 250毫克  |
| **五香豆干**       | 2塊     | 約110毫克 |
| **黑芝麻粉**       | 2湯匙    | 約130毫克 |
| **芥藍菜**        | 熟食約半碗  | 約180毫克 |
| **小白菜**        | 熟食約半碗  | 約100毫克 |
| **奇亞籽**        | 1湯匙    | 76毫克   |

> **飲食小提醒**：乳品、添加鈣飲品及可連骨食用的魚類，是較容易一次取得較多鈣質的食物。黑芝麻雖然含鈣豐富，但熱量也不低，比較適合作為配料，不宜為了補鈣一次吃下大量芝麻。小魚乾、蝦米、起司及部分豆干的鈉含量可能較高，也不適合無限制增加份量。

## 一天如何吃到約1,000毫克鈣

可以把鈣質分散在三餐與點心，不必集中在同一餐：

* **早餐**（合計約 305 毫克）：
  * 低脂鮮奶 1 杯：約 240 毫克
  * 黑芝麻粉 1 湯匙：約 65 毫克
* **午餐**（合計約 290 毫克）：
  * 五香豆干 2 塊：約 110 毫克
  * 熟芥藍菜半碗：約 180 毫克
* **下午點心**（合計約 240～300 毫克）：
  * 鮮奶 1 杯或有標示添加鈣的豆奶 1 杯：約 240～300 毫克
* **晚餐**（合計約 210 毫克）：
  * 傳統豆腐 1 塊：約 110 毫克
  * 熟小白菜半碗：約 100 毫克

如此一天約可取得 **1,045～1,105 毫克鈣**。實際飲食不必每天完全相同，可以在牛奶、優格、豆腐、豆干、帶骨魚、芝麻及深綠色蔬菜之間交替搭配。

## 提高補鈣效果的飲食方法

1. **將鈣質分散攝取**：人體一次攝取的鈣越多，吸收比例通常會下降。與其一餐大量補充，不如分散在早餐、午餐、晚餐與點心中。
2. **同時留意維生素 D**：維生素 D 能幫助腸道吸收鈣質。除了依個人情況適度日照，也可從鮭魚、鯖魚、蛋黃、菇類及添加維生素 D 的食品取得。
3. **選對豆腐種類**：並非所有豆腐的鈣含量都一樣。使用硫酸鈣作為凝固劑的傳統豆腐通常含鈣量較高；部分嫩豆腐使用其他凝固劑，鈣含量可能較少。最可靠的方式是查看成分及營養標示。
4. **蔬菜不能只看含鈣量**：菠菜雖然含有鈣，草酸含量也較高，會降低鈣的吸收。芥藍菜、小白菜、青花菜等草酸相對較低，可作為較實用的植物性鈣來源。
5. **減少過鹹飲食**：長期攝取過多鹽分會增加尿鈣排出。加工肉品、泡麵、醃漬品、重口味醬料及零食應適量。
6. **配合負重與阻力運動**：鈣質是骨骼的原料，運動則是刺激骨骼維持強度的重要因素。健走、爬樓梯、慢跑、跳繩、深蹲及肌力訓練都可依體能安排。

## 乳糖不耐或吃素如何補鈣

### 乳糖不耐者

乳糖不耐不代表完全不能碰乳品。可以嘗試：

* 選擇無乳糖或低乳糖牛奶
* 從少量開始並隨餐飲用
* 改吃優格或適量起司
* 使用添加鈣豆奶補充

### 全素飲食者

可優先選擇：

* 有清楚標示鈣含量的植物奶（使用前先搖勻，避免鈣質沉澱於底部）
* 硫酸鈣製成的傳統豆腐
* 豆干、豆皮與黃豆
* 芥藍菜、小白菜及青花菜
* 黑芝麻及奇亞籽

## 什麼情況才需要鈣補充品

飲食應是鈣質的主要來源。如果經過飲食調整後仍無法達到建議量，或醫師評估有骨質疏鬆、吸收不良等情況，才考慮使用補充品。

### 挑選與服用重點

* **確認「元素鈣」含量**：選購時應看元素鈣含量，而不是只看碳酸鈣或檸檬酸鈣的化合物總重量。
* **碳酸鈣**：元素鈣比例較高，通常建議隨餐服用。
* **檸檬酸鈣**：較不依賴胃酸，可空腹或隨餐服用；胃酸較少或使用抑制胃酸藥物者，可向醫師或藥師詢問是否較適合。
* **單次劑量限制**：每次元素鈣以不超過 500 毫克為原則，需要較多劑量時可分次補充。

> **安全警語**：鈣片可能引起便祕、脹氣或腸胃不適。腎功能異常、曾有腎結石、高血鈣或副甲狀腺疾病者，不應自行大量補充。鈣補充品也可能影響甲狀腺素及部分抗生素等藥物的吸收。固定服藥者應先詢問醫師或藥師，不要自行決定服用間隔。

## 常見補鈣迷思

### 喝大骨湯可以補鈣嗎？

骨頭本身含有鈣，但一般熬煮進湯裡的鈣非常有限。大骨湯不能取代牛奶、豆腐、帶骨小魚等高鈣食物。

### 有抽筋就是缺鈣嗎？

抽筋可能與疲勞、脫水、運動過度、神經或循環問題有關，不能只憑抽筋認定缺鈣。反覆或嚴重抽筋應尋求醫療評估。

### 補越多鈣，骨頭就越強嗎？

不是。骨骼健康還需要維生素 D、足夠蛋白質、規律運動與正常荷爾蒙功能。鈣攝取過量也可能造成便祕、腎結石風險或藥物交互作用。

### 吃鈣片就不用調整飲食嗎？

鈣片只能補充特定營養素，無法取代天然食物中的蛋白質、維生素及其他礦物質。原則仍是食物優先，補充品補足差額。

## 日常補鈣重在長期累積

補鈣不是短期衝刺，而是每天穩定累積。一般成人可把每日 1,000 毫克當作飲食安排目標，利用 1.5～2 杯乳品，再搭配豆製品、深綠色蔬菜、芝麻或帶骨魚類，通常比只依賴鈣片更容易建立完整而持久的飲食習慣。

若有骨質疏鬆、腎臟疾病、腎結石、高血鈣、吸收不良，或正在服用固定藥物，補充鈣片前應先諮詢醫師、營養師或藥師。
